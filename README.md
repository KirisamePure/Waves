# Waves

Minecraft **1.21.10 / Fabric / Java 21** 的客户端海浪 Mod。Mod 负责方块检测、天气、配置与水花，Iris 着色器负责水面绘制；它不是只装一个光影 ZIP 就具备全部功能的独立光影包。当前仍需开启 Iris 光影。水面使用八组交叉波、非整比波长、相位扭曲和变化浪群，雷暴时显著增强。

## 安装与使用

1. 安装适用于 **1.21.10** 的 Fabric Loader（≥ 0.17.3）。
2. 在客户端 `mods/` 放入 Fabric API **0.138.4+1.21.10**、Iris **1.9.7**、Sodium **0.7.3** 和 `waves-0.2.0.jar`。
3. 进入世界后按 **O**，点击 **「启用海浪（参考光影）」**。这会明确选择并启用附带光影，无需手动找文件。仅安装 Iris 不等于启用了光影：光影关闭时水面不会改变。Mod 首次启动会将 **Waves-Reference-0.2.0.zip** 安装到 `shaderpacks/`，不会覆盖已有同名文件。
4. 进入世界后按 **O** 打开中文/英文配置界面。快捷键可以在原版「选项 → 控制 → 按键绑定」中修改。

**只需要客户端安装。服务器无需 Fabric、Iris 或 Waves。** 所有位移都是视觉效果，服务器的水体、游泳判定、浮力、船只和碰撞维持原版行为。

## 不规则海浪与拍岸反馈

- 八组不同尺度和方向的波叠加；「不规则度」控制方向离散、相位扭曲与浪群调制，减少整排、等距的波纹。
- 客户端读取海平面附近的实际方块碰撞形状，建立距离场；波浪在礁石边界衰减，并在附近叠加回荡波纹。
- 浪峰抬升并到达岸礁接触点时产生短促水花和白色喷沫，受冷却与数量预算限制。
- 附带参考光影增加随波变化的拍岸泡沫和雷暴白浪。第三方光影保留自己的表面材质，不能保证出现同样的表面泡沫。
- 按 O 的第三页可配置衰减范围、回荡强度、泡沫、水花开关与密度。

这些是基于实际障碍物的**视觉近似**：不是流体动力学求解，不会绕礁石计算真实水流，不会打碎方块、推船或改变浮力。

默认晴天振幅为 0.32 格，下雨倍率 1.6，雷暴倍率 5（约 1.6 格振幅），天气变化平滑过渡。可点击「汹涌海洋预设」获得更大的涌浪。

## 按 O 能打开，但水面没变化

先看设置页顶部状态，而不是仅凭快捷键判断：

- **「未启用 Iris 光影」**：点击「启用海浪（参考光影）」，等待编译完成再返回游戏。进世界后也会显示一次提醒。
- **「海浪开关已关闭」或「基础波高为 0」**：开启海浪并提高基础波高。
- **「仅主世界」的维度提示**：关闭范围限制，或回到主世界。
- **接口未连接 / 无独立水材质 ID**：换用附带参考光影；不能只根据 Iris 已安装就判定其生效。
- **接口已连接仍无波浪**：查看顶部的当前振幅和海平面 Y；自定义海平面可临时关闭「仅海平面附近」来排查。反馈时附两页配置截图和光影名称，才能区分材质适配、范围过滤及参数问题。

启用按钮是显式选择参考光影，不会在启动时擅自替换现有光影。升级时请删除旧版 Waves JAR，只保留一个版本。

## 可配置项

按 O 调整后即时生效，点击「完成」或按 Esc 保存到 `config/waves.json`，无需重建区块或重新编译光影。

| 参数 | 范围 / 默认值 | 作用 |
| --- | --- | --- |
| 海浪开关 | 默认开启 | 关闭时输出零位移 |
| 基础波高 | 0–2 / 0.32 | 晴天的位移振幅，单位为格 |
| 波长 | 8–96 / 24 | 主波波长，另外七组波更短（最短不低于 3.5 格） |
| 速度 | 0–4 / 1 | 传播速度倍率，0 冻结动画 |
| 风向 | 0–360° / 35° | 主波传播方向 |
| 浪峰锐度 | 0–1 / 0.65 | 二次谐波塑造尖锐浪峰 |
| 不规则度 | 0–1 / 0.75 | 波向离散、相位扭曲和变化浪群 |
| 岸礁反馈 | 默认开启 | 根据实际附近方块衰减并叠加回荡 |
| 岸边衰减范围 | 0.5–8 格 / 3 | 离障碍多远恢复完整振幅 |
| 回荡强度 | 0–1 / 0.35 | 视觉反射波纹 |
| 泡沫强度 | 0–1.5 / 0.8 | 参考光影的表面泡沫 |
| 拍岸水花 | 默认开启 | 浪峰接触岸礁时生成客户端粒子 |
| 水花密度 | 0–1 / 0.6 | 接触水花的触发密度 |
| 下雨倍率 | 1–5 / 1.6 | 完全下雨时的振幅倍率 |
| 雷暴倍率 | 下雨倍率–10 / 5 | 完全雷暴时的振幅倍率 |
| 天气过渡 | 0.25–30 秒 / 8 秒 | 天气强度的指数平滑时间常数 |
| 海平面 Y | −64–320 / 63 | 自定义世界可调整 |
| 仅海平面附近 | 默认开启 | 限制到海平面附近约一格的水体，并做垂直淡出 |
| 仅主世界 | 默认开启 | 避免影响其他维度 |

最终位移振幅上限为 6 格，防止极端设置造成过度穿模。海平面筛选依据高度，**不是生物群系**：同高度的湖泊也会起浪；岸礁反馈另行扫描海平面附近的实际实体方块。

## Iris 兼容范围

本版本以 **Iris 1.9.7 + Sodium 0.7.3** 为目标。通过 Iris 的 `TransformPatcher.patchSodium` 在地形着色器进入 Iris 转换前包装顶点入口，给水顶点施加位移，并更新向上表面的几何法线。动态 uniform 提供配置、天气与高精度相位，不修改磁盘上的第三方光影包。

附带的 **Waves Reference** 是用于验证和基础游玩的简易光影，包含基础水面 Fresnel、高光、拍岸泡沫与白浪，不是完整的电影级光影包。

岸礁距离场覆盖玩家周围 128×128 格，每游戏刻扫描 8 行，完整刷新约需 16 刻；只读取已加载区块，不主动加载远处区块。边缘平滑过渡到无岸礁效果。实体检测范围为配置海平面 Y 的 Y−2 至 Y，碰撞体按所在格近似，因此不是对任意高度的瀑布、不同海拔河流或细小碰撞体的精确求解。水花接触点限玩家 28 格内，每刻最多检查 12 个接触点，每点有冷却和粒子数量预算。关闭「岸礁反馈」可停用距离场反馈，关闭水花可减少粒子。

第三方光影需要使用 Iris 兼容式地形输入（`gl_Vertex` 或 `ftransform()`），并在 `block.properties` 中为 `minecraft:water` 分配独立的材质 ID。无法识别水材质时停止施加波浪，避免玻璃、熔岩等方块被误移动。自定义核心顶点输入的光影保持原样。

请关闭第三方光影自带的**水面顶点位移**，防止两套波浪叠加；法线贴图仍可保留。自行重算法线、屏幕空间反射、水下折射、几何/曲面细分、体素化和特殊阴影流程可能需要针对该光影的适配，不能保证任意光影包无缝兼容。Distant Horizons 远景水面不在此版本支持范围内。

本 Mod 不增加网格细分。极短波长受原有方块网格精度限制，极大波高仍可能在复杂岸线、半砖或区块视锥边缘产生穿插或裁剪；局部岸礁衰减减少了贴岸穿模，但不保证完全消除。为了保证动态水面起伏，本版本需要**启用 Iris 光影包**；关闭光影时不提供原版渲染后备效果。

## 构建与验证

```sh
# 本地安装 JDK 21 后：
./gradlew build

# 云环境（自动使用已有代理与 /workspace 下的 JDK / Gradle 缓存）：
bash tools/setup_cloud.sh
python3 tools/gradle_cloud.py build
```

产物：

- `build/libs/waves-0.2.0.jar`：发布用 Mod，内部包含基础光影包。
- `build/libs/Waves-Reference-0.2.0.zip`：也可单独复制到 `shaderpacks/`。
- `build/libs/waves-0.2.0-sources.jar`：源码包。

`build` 执行 `coreTest`：检查天气倍率、平滑、相位、着色器入口改写、参数约束和配置损坏恢复。图形测试在独立的测试 Mod 中，不打进发布 JAR：

```sh
# 需要可用的 X11/OpenGL 显示，或 CI 中的软件 OpenGL 虚拟显示：
./gradlew runClientGameTest

# 当前云环境已有 Xorg dummy + Mesa，可自动创建并清理虚拟显示：
python3 tools/render_test_cloud.py

# 验证实际发布 JAR 和生产 Fabric Loader（不使用开发类替代 Mod）：
python3 tools/render_test_cloud.py --production
```

图形测试创建原版地形世界，寻找自然深海，从光影关闭状态点击游戏内启用按钮，检查 Iris 接口、动画相位推进、晴天/雷暴振幅、礁石放置与移除后的距离场更新、GPU 距离场、水花触发和三页中文设置，并保存截图。不要在真实存档中运行测试。

云环境开发图形测试日志位于 `build/reports/render/client-test.log`，截图位于 `build/run/clientGameTest/screenshots/`。生产 JAR 测试使用 `build/reports/render-production/client-test.log` 和 `build/run/productionClientGameTest/screenshots/`。`--skip-assets` 仅用于诊断资源下载故障；缺失字体时 Minecraft 不能完成加载，不能据此宣称图形测试通过。
