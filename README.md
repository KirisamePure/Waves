# Waves

Minecraft **1.21.10 / Fabric / Java 21** 客户端海浪 Mod。**不需要 Iris，不需要光影包**：直接扩展 Sodium 的地形渲染，让实际水面顶点随波移动。雷暴增强波涛；岸礁附近有回荡、白沫、向上飞溅的水滴和拍岸音效。按 **O** 实时配置。

## 安装

1. 安装 Fabric Loader **≥0.17.3**、Fabric API **0.138.4+1.21.10**、Sodium **0.7.3**。
2. 将 `waves-0.4.0.jar` 放入客户端 `mods/`。移除旧版 Waves JAR。
3. 启动游戏即可起浪，不需要选择任何光影包。按 **O** 配置，快捷键可在原版按键绑定中修改。

**只装客户端即可。服务器无需安装任何前置或 Waves。** 不注册服务器入口或自定义网络协议，不改变水流、游泳、浮力、船只和方块碰撞。

从 0.1/0.2 升级后不再需要 Waves Reference。可在 Iris 中关闭光影，或直接选择自己的光影；Mod 不会安装、替换或切换用户的光影包。旧配置会保留，新增设置使用默认值。

## 海浪与拍岸

- 八组不同尺度、方向和非整比波长的波，结合相位扰动、浪群变化，减少整排、等距波纹。
- 默认晴天振幅 0.32 格，下雨倍率 1.6，雷暴倍率 5，平滑过渡，最终振幅上限 6 格。
- 基于实际岸礁碰撞方块建立距离场，近岸保留至少 72% 波高，仅在较短距离内轻微过渡，并叠加回荡波纹，避免岸边出现被固定的平面。原生水面的近岸白沫随浪头间歇聚散。
- 浪峰升起到达岸礁接触点时，发射一簇**原版 `SPLASH` 水花粒子**，使用 Minecraft 自带的像素水花贴图和粒子更新逻辑，不再注册自定义蓝色椭圆水滴。可单独配置密度、发射高度和可见尺寸，并遵循原版粒子显示设置。
- **靠近岸边持续播放海浪环境声**，与浪峰、水花和动画速度无关；走近时淡入，远离、关闭或切换世界时淡出/停止。使用 SecureSubset 的 CC0 太平洋拍浪录音，制作成 20 秒交叉淡化循环，固定原始音高，仅运行一个声音实例；默认范围 24 格，可配置 8–28 格。受原版「环境」和主音量控制，支持字幕。

- **浪头上岸与退水**：对海水连通的低岸面单独生成动态透明水层。只有浪头超过地面和沿途障碍时才覆盖，浪退后逐渐消退，减少原版水面几何只到水方块边界的截断感。与相邻海水使用同一波形，岸面网格细分为半格，提供 1–8 格可配置覆盖范围。
- **天气风声**：使用 felix.blume 的 CC0 自然风录音循环。雨天渐强、雷暴更强、晴天淡出；可调阵风与音高，默认在室内和水下减弱。不依赖岸边浪声或水花事件。

这些是基于实际障碍物的**客户端视觉与声音近似**，不是流体动力学求解；不会模拟真实绕流或用波浪推船。岸上薄水层不会生成实际水方块，不改变作物、红石、实体碰撞或服务器状态。

## 配置

按 O 打开六页设置，立即生效，完成后原子保存到 `config/waves.json`。关闭某项效果无需重启或重载区块。

| 页面 | 参数 |
| --- | --- |
| 海浪形态 | 总开关、晴天波高、波长、速度、风向、浪峰锐度、不规则度 |
| 天气与范围 | 雨天/雷暴倍率、过渡时间、海平面高度、仅海平面、仅主世界、重置 |
| 岸边与礁石 | 岸礁反馈开关、水花开关、近岸衰减范围、回荡、白沫、水花密度、汹涌海洋预设 |
| 水花与音效 | 岸边环境声开关、音量、范围、水花向上发射速度倍率、水滴尺寸 |
| 溢水与退浪 | 岸上溢水开关、最远距离、薄水层可见度、退水时间 |
| 风暴风声 | 独立开关、音量、音高、雨天/雷暴强度、阵风变化、室内及水下减弱 |

速度 0 冻结波浪并停止新的撞岸水花；岸边环境声继续播放。水花和音效可分别关闭。无光影时状态显示「原生 Mod 海浪」。

## 可选 Iris 光影

可以额外安装 **Iris 1.9.7** 并使用自己的光影包，无需附带参考包。请关闭光影自带的水面顶点波动，避免叠加。

不开光影时，海浪、表面白沫、水滴和声音全部走 Mod 原生路径。开启 Iris 后，Mod 通过可选适配器将同一海浪位移和法线接入当前光影的地形程序，水滴与声音仍由 Mod 生成。没有 Iris 时不会加载相关 Mixin。

兼容前提：光影使用 `gl_Vertex` / `ftransform()` 兼容式地形输入，并在 `block.properties` 为水指定独立材质 ID。自定义核心顶点布局、几何/曲面细分、体素化或特殊反射/水下流程可能需要单独适配。仅仅关闭光影自带波动不能保证任意光影兼容；不支持时设置页会说明。第三方光影保留自己的表面着色，**原生白沫不会自动替换对方材质**；抛射水滴和音效不依赖该材质。Distant Horizons 远景水面暂不支持。

## 范围与性能

距离场覆盖玩家周围 **128×128** 列，每游戏刻扫描 8 行，约 0.8 秒更新一轮。只读取已加载区块；检测配置海平面 Y−2 到 Y 的碰撞形状，每列近似为占据/未占据，不求解半砖或栅栏的精细形状。水花接触点限玩家 28 格内，每刻最多检查 12 点，单点有冷却，每刻最多发射 96 个水滴。水花尺寸、高度和密度可在设置页调整，原版“最少”粒子设置下不发射额外水花。声音根据三维离岸距离渐变，不依赖撞岸冷却。

岸上薄水层单独使用 Fabric 世界渲染事件，原生及可选 Iris 路径均保留深度测试。只覆盖检测到的完整平顶碰撞面（含平顶半砖），不尝试填充楼梯、栅栏等复杂形状；以海平面附近最高 6 格的局部地形为范围，每次最多保留 2048 个、玩家 40 格内的候选岸面，只有湿润的面才绘制。不是完整地形洪水模拟。第三方光影对实体透明层的反射、折射可能与其自身水材质不同，仍可能需要专门适配。

海浪渲染覆盖正常 Sodium 水面，不受距离场窗口限制；窗口边缘平滑淡出近岸衰减。自定义世界需正确设置海平面。粒子显示还受原版粒子设置影响。

## 构建与验证

```sh
./gradlew build
```

产物：`build/libs/waves-0.4.0.jar`。需要 JDK 21。

云环境可使用 `bash tools/setup_cloud.sh`，或 `python3 tools/gradle_cloud.py build --no-daemon`。脚本使用可写缓存、已有网络代理及系统证书，不关闭 TLS 校验。

```sh
# 实际重映射 JAR；不安装 Iris
python3 tools/render_test_cloud.py --production --no-iris
# 原生路径 + 可选 Iris 的无自带水面位移测试光影
python3 tools/render_test_cloud.py --production
```

测试光影仅随独立测试 Mod 打包，不进入发布 JAR。详见 [VALIDATION.md](VALIDATION.md)。测试覆盖云环境软件 OpenGL；不代表所有实体显卡或第三方光影均已验证。

拍岸录音来源、作者、CC0 授权和修改说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)，该说明也包含在 JAR 内。`tools/prepare_surf_audio.py` 和 `tools/prepare_wind_audio.py` 可从校验过的录音重现两个 20 秒循环。

本项目独立实现岸上薄水层；用户提供的 Puddles & Floods 仅用于了解期望效果，阅读了公开 README，没有复制其源码或资源。
